Noto Sans SC · Google Fonts / Noto CJK

Source: https://github.com/google/fonts/tree/main/ofl/notosanssc

SIL Open Font License 1.1; see OFL.txt. Content-specific Unicode subsets, weights 400 and 700. Regenerate when adding Chinese text. Full source font is retained outside the repository.

Regenerate with `python scripts/subset-chinese-font.py <official-variable-font.ttf>`
from the repository root (requires fontTools and Brotli). The script preserves
existing coverage, adds the Chinese content characters and updates the font URL
versions in `assets/css/extended/typography.css`.
